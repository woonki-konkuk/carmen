# 카르멘 산디에고 — 파리의 눈물

넷플릭스 애니메이션 〈카르멘 산디에고〉를 좋아해서 만든 비공식 팬 게임입니다. 원작의 제작사와는 관계가 없고, 돈을 벌려고 만든 것이 아닙니다.

카르멘이 되어 파리의 세 구역을 걸어 다니며 바일(V.I.L.E.) 조직원에게서 '눈물' 보석 세 개를 되찾습니다.

- 몽마르트르: 달아나는 마임 밤을 쫓아가 소매치기
- 에펠탑 · 샹드마르스: 페이퍼 스타와 모자 던지기 전투
- 루브르 · 튈르리: 타이거리스와 주먹 전투

보석을 되찾으면 ACME의 데비노 형사를 피해 지하철 입구까지 달아나야 합니다.

## 실행

라이브러리도 빌드도 없는 HTML과 자바스크립트입니다. 그림과 소리, 음악은 모두 코드로 만들어 냅니다.

```bash
python3 serve.py
```

그런 다음 브라우저에서 `http://localhost:8765/`를 엽니다.

## 조작

- `W` `A` `S` `D` 걷기, `Shift` 뛰기, 마우스나 `←` `→`로 둘러보기
- `E` 소매치기·확인, `Tab` 휴대폰
- 전투: `A` `D` 피하기, `S` 막기, `Space` 주먹이나 모자 던지기
